# HandsOn Frontend

신규 연구생의 실험 절차 실행과 숙련자의 절차 관리를 지원하는 HandsOn Android 앱입니다.

## 기술 방향

- React Native · Expo development build
- TypeScript · Expo Router
- Aurora Lab 디자인 시스템 · React Native StyleSheet

## 현재 상태

프로젝트 초기 세팅과 공통 컴포넌트 구현을 준비하고 있습니다. API, 센서, 음성 및 AI 연동은 후속 작업입니다.
