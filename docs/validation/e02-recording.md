# E02 음성 설명 녹음

이슈 #8의 구현과 검증 범위입니다. 디자인은 첨부 SVG의 E02 및 Recording paused 화면을 기준으로 기존 디자인 시스템을 재사용합니다.

## 원본 저장과 E03 전달

2026-11-05 사용자 확인에 따라 AAC/M4A 음성을 앱 내부에 저장합니다. 파일 ID, 로컬 URI, 파일명, MIME 형식(`audio/mp4`), 실제 녹음 길이, 바이트 크기, 저장 시각, 절차 이름과 선택한 작업 환경을 함께 보관합니다.

E02가 파일 저장과 메타데이터 기록을 마친 뒤 `recordingId`만 E03 경로에 전달합니다. E03은 ID로 저장 정보를 읽고 원본 존재·크기·길이를 확인합니다. URI를 라우트 입력으로 받아 임의 파일을 참조하지 않습니다. STT 서비스와 외부 전송 형식은 아직 연결하지 않았으며 E03의 요청·편집 동작은 #9 범위입니다.

정상 저장한 원본은 화면 이탈로 삭제하지 않습니다. E03의 **원본 삭제하고 돌아가기**에서 사용자가 삭제할 수 있습니다. 자동 만료·서버 업로드·저장된 녹음 목록은 현재 범위에 없습니다.

## 중단과 실패

- 권한은 녹음 시작 시 확인합니다. Android 권한 창으로 잠시 앱을 벗어나면 권한 응답을 기다리고, 앱으로 돌아온 후에만 녹음을 시작합니다. 거부하면 다시 요청하거나 기기 설정으로 이동할 수 있습니다.
- 일시정지는 같은 녹음을 유지하고 경과 시간을 멈춥니다. 녹음 재개는 같은 원본을 이어 씁니다.
- 녹음 중 뒤로 가기는 취소 확인을 표시합니다. 삭제를 선택하면 녹음을 해제하고 미저장 파일을 정리합니다.
- 앱이 백그라운드로 이동하거나 화면이 포커스를 잃으면 미저장 녹음을 중단·정리하고 안내합니다. 백그라운드 녹음과 중단된 음성의 자동 복구는 제공하지 않습니다.
- 녹음·저장 오류, 길이 0 또는 빈 파일로 E03에 진행하지 않습니다. 생성 중이던 파일과 부분 메타데이터는 정리합니다.
- 파형은 네이티브 마이크 입력 크기이며, 하단의 준비물·작업 순서·주의사항·완료 기준은 설명을 돕는 안내입니다. 인식한 텍스트나 STT 완료 상태가 아닙니다.

## 검증

2026-11-05, Node 24.3.0에서 확인했습니다. 로컬 Android 에뮬레이터는 사용하지 않았습니다.

- `npm run typecheck`, `npm run lint`, `npm run format:check`: 통과했습니다.
- `npm run test:ci`: 9개 suite, 69개 테스트가 통과했습니다. 녹음 상태·권한 창에서의 일시적인 백그라운드 전환·거부·정지·저장 실패·중복 조작·준비 및 저장 도중 취소·파일 경로와 메타데이터 검증을 포함합니다. 네이티브 장치 동작은 단위 테스트에서 대체합니다.
- `npm run doctor`: 20/20 통과했습니다.
- `npm run export:android`: Android Hermes 번들을 생성했습니다.

Android 네이티브 흐름은 PR의 `Maestro Android` 결과와 `maestro-android` 아티팩트에서 확인합니다. `recording-android.yaml`은 시스템 권한 허용·실제 녹음 시간 증가·뒤로 가기 후 계속 녹음·일시정지·재개·종료·E03 원본 조회를 검사합니다. `recording-permission-android.yaml`은 권한 거부·홈 복귀·권한 허용 후 재시도·녹음 삭제를 검사합니다. 준비·녹음·일시정지·원본 전달·권한 거부 화면을 캡처합니다.

Maestro는 기존 CI의 실제 release APK와 네이티브 녹음 경로를 사용합니다. `EXPO_PUBLIC_HANDSON_MAESTRO=1`은 기존 작업 환경 fixture만 활성화하며 녹음 성공이나 음성 파일을 모의 생성하지 않습니다.

## 확인 한계

CI 에뮬레이터에서 확인하는 권한·녹음 상태·파일 저장·화면 이동은 실제 사람의 목소리와 물리 기기 마이크 품질을 입증하지 않습니다. 물리 Android 기기의 권한 요청, 전화·오디오 장치 분리에 따른 중단, 저장된 원본의 청취·디코더 검증은 별도로 필요합니다. 운영체제가 프로세스를 강제 종료한 경우 진행 중 녹음은 복구하지 않습니다.
