# E04 AI 절차 초안 검증

2026-11-12 · Node 24.3.0 · Expo 58.0.23 · Chromium

## 화면과 저장 동작

- 첨부 Figma SVG의 기본 화면과 저장 완료 화면을 기준으로 구현했습니다. 16단계를 7개 묶음으로 표시하고, 묶음을 열면 개별 단계를 선택하고 편집할 수 있습니다. 준비물과 주의사항은 `더 보기`에서 편집합니다.
- 임시 저장에 성공하면 처리 결과를 표시합니다. 기준값 검토로 이동할 때 편집한 내용이나 아직 저장하지 않은 초안이 있으면 먼저 저장합니다. 이 단계에서 저장에 실패하면 현재 화면에 편집값을 유지합니다. 자동 저장 주기는 API 계약과 함께 확인해야 합니다.
- 저장하지 않은 변경 내용이 있으면 화면을 나갈 때 편집을 계속하거나 변경 내용을 버릴 수 있습니다. 임시 저장한 초안은 승인 전 상태와 미확정 항목을 유지합니다.

## 확인 범위

- Playwright에서 412px·360px 숙련자 홈의 E04 진입, 단계 내용·순서·준비물·주의사항의 저장과 복원, 같은 초안과 단계의 기준값 검토 전달, 저장 실패 후 변경 내용 유지·버리기, 모의 생성 초안의 재진입을 확인했습니다.
- E03 연결 지점은 `/expert/drafts/[draftId]`입니다. 브라우저 검증은 생성 응답을 모의한 초안 ID를 실행 중인 앱에 전달합니다. E05 진입 경로는 같은 초안 ID와 선택한 `stepId`로 저장된 내용을 조회합니다. STT·AI 생성 요청과 E05 기준 편집은 각각 #9와 #11에서 연결합니다.
- 저장은 웹 `localStorage`와 Android 앱 내부 파일을 사용하는 개발용 모의 구현입니다. 실제 서버 API, Android 실행 중의 파일 저장·키보드·제스처 확인은 미실시입니다.
