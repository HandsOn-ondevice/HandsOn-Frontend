# E07 연구생 결과 검토

숙련 연구생으로 **전자회로 실험실**에 들어가 **노준혁 · LED-M03** 결과를 선택합니다. 화면 상단의 **더 보기**에서 제출 세션 `R-241015-07`, 절차와 승인 버전 `v1.2`를 확인할 수 있습니다.

- **50% 조건 센서 오류** 또는 차트의 **50%**를 누르면 회차별 기록을 엽니다. 무효 측정 420 lx, 케이블 재연결, 재측정 423 lx를 각각 확인할 수 있습니다. 결과 검토 화면으로 돌아와도 입력한 의견이 유지됩니다.
- **검토 완료** 또는 **재측정 요청**을 선택하면 각각의 처리 결과를 표시합니다. 숙련자 홈 **현황**에서 해당 상태를 선택해 결과와 저장한 의견을 다시 확인할 수 있습니다.
- **김민지 · LED-M02**의 **100%** 조건은 결측으로 표시됩니다. 상세를 열면 평균이나 근거가 없는 상태를 확인할 수 있습니다.

## 검증

- Chromium 412×920 및 360×800: 숙련자 홈에서 결과 진입, 조건별 근거 조회, 검토 의견 유지, 두 처리 결과와 홈 상태 갱신을 확인했습니다. 재측정 요청 후에도 기존 무효 근거를 다시 열 수 있습니다.
- Jest: 조회 실패 후 같은 결과 재조회, 저장 중 중복 입력 차단, 저장 실패 후 의견 유지와 재시도를 확인했습니다.
- Android 배포용 JavaScript 번들을 생성했습니다.
- Android 16(API 36) Medium_Phone 에뮬레이터: 숙련자 홈에서 결과와 50% 조건 상세를 열고, 시스템 뒤로가기로 검토 화면에 복귀했습니다. 검토 완료와 재측정 요청의 처리 결과도 확인했습니다. 의견 입력 시 [입력란과 두 동작이 키보드 위에 표시](e07-android-keyboard.png)되며, 시스템 뒤로가기로 키보드를 닫아도 입력 내용이 유지됩니다.

## 연동 범위

조회와 저장은 개발·Maestro 빌드의 합성 데이터로만 실행합니다. 의견과 상태는 앱 실행 중에 유지되며, 재측정 요청은 기존 근거를 변경하거나 세션을 다시 열지 않습니다. 실제 서버의 결과·근거 조회 및 저장 계약, 재측정 요청 범위와 권한 정책은 확정 후 연결해야 합니다. 실물 장치에서 측정·재측정을 실행하지 않았습니다.
