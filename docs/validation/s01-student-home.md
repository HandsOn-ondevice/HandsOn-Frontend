# S01 연구생 홈 검증

검증일: 2026-11-05. Node 24.3.0, Expo SDK 58, React Native 0.88 환경에서 개발용 합성 응답으로 확인했습니다.

## 확인한 동작

- Jest에서 홈 조회 로딩·오류·재시도, 환경 변경과 화면 이탈 뒤 늦게 도착한 응답 무시, 화면 재진입과 앱 활성화 시 재조회를 확인했습니다.
- 홈 표시 테스트는 진행 중 작업과 빈 상태, 승인 절차 선택, 최근 결과 식별자 전달, 하단 내비게이션과 프로필의 환경 재선택을 다룹니다. 이어하기에서 기존 세션 ID만 넘기고 원래 절차 버전·환경·장치 설정을 변경하지 않는지 확인했습니다.
- Chromium E2E에서 실제 홈의 이어하기·절차 선택·최근 결과·이력·장치 경로와 홈 복귀, 환경 재선택을 확인했습니다. 작업 환경을 바꾸면 이전 작업을 숨기고 빈 목록을 표시합니다. 홈 복귀 버튼을 이용한 뒤에도 환경 선택으로 돌아갑니다.
- 프로필은 시트가 닫힌 뒤 환경 선택 화면으로 이동합니다. 닫기 전에 이동해 다른 역할 화면에 시트가 남는 문제를 수정했습니다.

## 실행 결과

- `npm run typecheck`: 통과
- `npm run lint`: 오류 없음. Expo가 생성한 `.expo/types/router.d.ts`의 불필요한 eslint-disable 경고 1건이 있습니다.
- 저장소 추적 파일과 이번 추가 파일의 Prettier 검사: 통과. 로컬 `npm run format:check`는 Git에서 제외된 런타임 `.omx/state/session.json` 서식 때문에 실패했으며, 해당 런타임 파일은 변경에 포함하지 않았습니다.
- `npm run test:ci`: 7개 suite, 44개 테스트 통과
- `npm run test:e2e`: Chromium 6개 테스트 통과
- `npm run doctor`: 네트워크 가능한 호스트에서 20/20 통과
- `npm run export:android`: Android Hermes 번들 생성 통과

## Android CI

사용자 요청에 따라 로컬 에뮬레이터 검증은 수행하지 않습니다. 기존 `Maestro Android` 워크플로가 `.maestro` 전체를 실행하므로 추가한 `student-home-android.yaml`도 실행 대상입니다. 진행 중 실험·승인 절차·결과·이력·장치 진입, 시스템 뒤로 가기와 홈 복귀, 프로필의 환경 변경, 빈 목록 상태와 캡처를 포함합니다.

## 남은 확인

실제 홈 API·장치 연결 상태는 미연동입니다. 홈에서 진입하는 S02–S15와 결과·이력·장치 화면은 준비 중 안내만 제공합니다. README에 있던 이어하기 경로를 사용했고, 나머지 경로는 현재 로컬 인계 경계입니다. A·서버 담당과 홈 응답, 진행 중 세션 상태, 결과·이력 경로 계약을 확정해야 합니다. 합성 응답·웹 E2E의 성공을 실제 세션 복구나 기기 연동 성공으로 해석하지 않습니다.
