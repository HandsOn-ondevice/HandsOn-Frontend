# E03 STT 텍스트 확인과 초안 생성

E02에서 받은 `recordingId`로 앱에 보관된 음성 원본을 확인합니다. 첫 변환 결과와 수정한 텍스트를 같은 ID 아래 저장합니다. 화면에 다시 진입하면 보관한 편집 내용을 불러오며, 변환을 다시 요청하는 경우는 저장된 텍스트가 없을 때입니다.

공백만 입력하면 초안 생성을 요청할 수 없습니다. 요청에는 녹음 ID와 마지막으로 확인한 텍스트를 전달합니다. 생성 요청 중에는 입력과 중복 제출을 막습니다. 실패하면 같은 텍스트로 재시도할 수 있고, 생성은 완료됐으나 초안 저장에 실패하면 같은 결과의 저장을 재시도합니다.

생성 결과는 녹음의 작업 환경과 초안 ID로 저장합니다. E04 편집 경로가 포함된 빌드에서는 해당 편집 화면으로 이동합니다. 현재 `main` 기준으로는 동일한 저장소에서 초안을 읽어 생성 결과를 표시합니다. E04 편집 화면은 #22에서 구현합니다.

## 개발용 응답

개발 빌드와 Maestro 검증 빌드에서 첨부 SVG의 LED 측정 예시를 모의 변환 결과로 표시합니다. 모의 변환은 Android에서 저장된 원본 메타데이터를 받으며 음성을 인식하거나 전송하지 않습니다. 초안에는 사용자가 확인한 텍스트를 그대로 담고 검토가 필요한 상태로 저장합니다. 개발 웹에서는 전자회로 실험실의 녹음 화면에서 **STT 확인 화면 미리보기**를 열 수 있습니다.

## 검증 범위

- Jest는 같은 녹음 원본으로 변환을 재시도하는지, 편집한 텍스트가 생성에 전달되는지, 요청 중 중복 제출을 막고 저장 성공 후 이동하는지 확인합니다.
- Chromium 360×800에서는 빈 입력 차단, 뒤로 이동 후 편집 복원, 초안 저장 실패 후 재시도와 E04 텍스트 표시를 확인합니다.
- Android Maestro 시나리오는 실제 에뮬레이터 녹음이 E03의 모의 변환과 생성 결과 화면으로 이어지는지 확인하도록 갱신했습니다. 로컬 Android 실행과 물리 기기 검증은 미실시입니다.
- 실제 STT·AI API와 응답·재시도 계약은 확인이 필요합니다. 일반 배포 빌드에는 서비스 연결 대기 상태가 표시됩니다.
