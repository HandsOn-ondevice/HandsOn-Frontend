# US-01~03 승인 절차 인계 검증

숙련자가 시연 전사문으로 절차를 작성하고 승인한 뒤 독립 연구생 브라우저에서 같은 버전의 준비를 시작하는 구간을 검증합니다. 두 브라우저 컨텍스트는 같은 로컬 Edge와 지급 키트 실습실(`kit-lab`)을 사용합니다.

## Playwright UI에서 실행

Node 24.3.0, Playwright Chromium, Python 3.12 환경을 준비합니다. 아래 검증은 HandsOn-Backend의 [`67716a5` 커밋](https://github.com/HandsOn-ondevice/HandsOn-Backend/tree/67716a54ed80ea4f125d8241cf2c672fd73ba741)으로 실행했습니다. 해당 백엔드 체크아웃에서 `uv sync --frozen`으로 가상 환경을 준비한 뒤 Frontend 루트에서 다음 명령을 실행합니다.

```sh
# BACKEND_DIR에 위 커밋을 체크아웃한 HandsOn-Backend의 절대 경로를 지정합니다.
"$BACKEND_DIR/.venv/bin/python" e2e/support/edge-approval-server.py --backend-dir "$BACKEND_DIR"
```

Frontend 루트의 다른 터미널에서 다음 명령을 실행합니다.

```sh
HANDSON_E2E_EDGE_APPROVAL=1 EXPO_E2E_PORT=8153 \
  EXPO_PUBLIC_HANDSON_EDGE_BASE_URL=http://127.0.0.1:8053 \
  npm run test:e2e:ui -- e2e/edge-approval.spec.ts
```

Playwright UI에서 **US-01~03 숙련자가 승인한 절차 버전을 독립 연구생 브라우저에서 준비한다**를 실행합니다. 실행기는 루프백 Edge에 새 SQLite를 만들고 프로세스가 끝나면 폐기합니다. 재실행 전에 Edge 실행기를 종료하고 새로 시작합니다. 같은 서버에 시연 제목의 초안이 남아 있으면 테스트가 종료됩니다. 캡처와 `edge-approval-evidence` JSON은 Playwright UI의 첨부와 `artifacts/playwright/edge-approval/test-results/`에서 확인할 수 있습니다.

## 대조한 상태

| 구간          | 관찰 지점                                                                                                                                                                                                                                                         |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 초안 생성     | 테스트 오디오로 전사 화면에 들어갑니다. Edge의 시뮬레이션 API에 등록한 전사문이 생성 요청의 `confirmedText`와 같고, 응답과 화면에 승인 전 리비전 0의 7개 단계가 순서대로 표시됩니다.                                                                              |
| 승인 전 차단  | 실행 기준이 빠진 상태에서 승인 화면의 필수 확인과 사유를 채워도 승인이 비활성화됩니다. Edge도 `422 REVIEW_REQUIRED`로 거절합니다. 독립 연구생의 승인 목록에는 해당 ID가 없으며 해당 초안 버전의 세션 요청은 `404 NOT_FOUND`로 끝납니다.                           |
| 저장과 재조회 | 장치 연결 설명, 기준 미달 시 보류, 정상 기준 재확인 후 작업자의 명시적 재개 지시를 편집합니다. 리비전 1을 다시 열어 거리 15~25 cm, 조도 1500 ADC와 저장한 단계 설명을 확인합니다. 앱에는 조도가 **원시값**으로 표시되며 Edge 센서 응답에 단위 `adc`가 표시됩니다. |
| 승인과 준비   | 필수 확인이 남으면 승인 버튼이 비활성화됩니다. 최종 승인 후 숙련자 결과와 연구생 목록·상세에서 동일한 절차 ID와 버전을 확인합니다. 새 준비 세션의 생성·조회 응답에 같은 승인 버전과 실행 기준이 고정됩니다. Edge 상태 조회에서 시뮬레이션 LED는 `off`입니다.      |

Edge 시뮬레이션의 기본 생성기는 전사문을 한 단계로 엮습니다. 테스트 실행기는 지정한 제목과 전사문에 대해서만 7단계 생성 출력을 고정하고, 같은 Edge가 초안 저장·조회·버전 승인·세션 생성을 수행합니다. 거리와 조도는 실행 기준 필드로 저장되고 보류·재개 지시는 단계 설명에 저장됩니다. 실제 갤탭 녹음, STT, AI 생성 품질, 센서·LED 실물 동작은 촬영 리허설에서 확인할 범위입니다.
